GOLDEN - WHICH PHOTO GOES WHERE
================================

This folder holds every photo on the website. To change a photo, put your new
picture into the right folder with the SAME file name as the old one (or, in a
"carousel" folder, add / remove files - see below).

THE RULES (please read)
-----------------------
1. Each photo may be used ONLY ONCE on the whole site. Do not put the same
   picture (or a near-identical one from the same moment) in two places.
2. No photos of little girls.
3. Save photos as JPG (or PNG / WebP). iPhone "HEIC" files do NOT work: open the
   photo and "Save as JPG" / export as JPEG first. The website refuses to build
   while a HEIC file is in this folder.
4. Keep every file under about 5 MB. (Big camera files are shrunk automatically
   when the site is published, but small files make editing easier.)
5. The file name must match the spot name below. Capital letters do not matter,
   and .jpg / .jpeg / .png / .webp are all fine.
6. Swapping a file on your computer does NOT change the live website. The new
   photo only goes live when it is published: ask Claude to "publish the
   photos". Please do NOT upload photos straight to github.com: phone and
   camera photos carry hidden data (like the GPS location where they were
   taken), and anything uploaded there is public at once. Publishing through
   Claude removes that hidden data first.

THE SHAPE OF A PHOTO
--------------------
Photos are always shown WHOLE, not cropped, so the best photo is landscape
(wider than tall). Portrait photos also work in the single spots below, but they
are shown narrower on computers.

CAROUSELS (photos that fade into each other: 3:2 landscape please)
------------------------------------------------------------------
A carousel shows every photo in its folder, one after the other, in the order
of the file names. So name them 01 - ..., 02 - ..., 03 - ... The words after the
number are used as the picture description for blind visitors, so describe what
is in the photo, e.g.  "05 - two athletes smiling after a round.jpg".
Best shape: 3:2 landscape (like a normal camera photo). A photo that is much
taller or wider than that gets cropped and the build prints a warning.
On the HOME carousel a quote is written ACROSS THE TOP of the photo, so choose
photos with empty space at the top (a wall or ceiling) and no faces in the top
fifth. Put a new photo in by adding a file; remove one by deleting its file.
A carousel with only one photo stays still.
